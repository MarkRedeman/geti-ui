# OpenCV in `@geti-ui/smart-tools`

Smart tools use a custom OpenCV WASM build with a curated allow list of APIs.

## Build flow

Use the package script scaffold:

```bash
./packages/smart-tools/scripts/compile-opencv-wasm.sh
```

This script:

1. Clones OpenCV,
2. Uses `scripts/opencv_js.config.py`,
3. Runs the emscripten Docker build,
4. Produces `opencv.js` output for package usage.

## Why custom build

We compile only the APIs needed by Geti smart tools to reduce size and startup overhead.

## Configuring the source URL

`@geti-ui/smart-tools` does not bundle or serve the compiled `opencv.js` binary itself. Copy it
into your app's static assets and point smart-tools at it before using any OpenCV-backed tool
(GrabCut, Intelligent Scissors, Watershed, SSIM, RITM, Segment Anything):

```ts
import { setOpenCVSourceUrl } from '@geti-ui/smart-tools';

setOpenCVSourceUrl('/opencv/opencv.js');
```

If this isn't called, OpenCV-backed tools throw a descriptive error the first time they try to
load `opencv.js` — there's no default/CDN fallback.

## Restrictions

- Only allow-listed methods are available.
- Adding new OpenCV APIs requires an allow-list update + rebuild.
- Browser/worker runtime assumptions apply.
